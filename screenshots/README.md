# Screenshots

Capture these from your own running dashboard (never mock them up). Use a 1440x900 window, browser zoom 100%, and the real dataset.

| File | How to capture |
|---|---|
| `01-national-overview.png` | Section **Overview**, no location selected, scroll to include KPIs + map |
| `02-location-analysis.png` | Pick a location (e.g. the one you know best) -> **Location** |
| `03-regional-comparison.png` | **Compare**, two regions selected, comparison bars + seasonal pattern visible |
| `04-seasonal-intelligence.png` | **Seasonal**, monthly chart and heatmap |
| `05-high-rainfall-screening.png` | **Event screening**, row selected so the "Why was this flagged?" card shows |

Tip: in Chrome, DevTools -> Ctrl+Shift+P -> "Capture full size screenshot". Save into this folder and reference them in the README.
